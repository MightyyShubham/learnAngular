Refactoring of a form from template-driven to a reactive form

Comparison between template-driven and reactive forms - when to use each and why

Template-driven forms use Angular directives such as ngModel to create and manage form controls directly in the HTML template. Reactive forms define the entire form structure in the TypeScript component using FormGroup, FormControl, and FormBuilder. Use Template-Driven Forms when you need a simple form with basic validation and want to develop it quickly. Use Reactive Forms when you need full control over the form, advanced validation, dynamic form fields, or better scalability and testability.

The formGroup and formControlName, and formControl directives

The formGroup directive binds an HTML < form >element to a FormGroup object created in the component.

The formControlName directive connects an individual form element to a FormControl inside a FormGroup.

The formControl directive binds a form element directly to a standalone FormControl object. Unlike formControlName, it does not require a parent FormGroup.

Backend validation of a form field using async validators

Angular Async Validators are used when form validation depends on backend data. They return an Observable or Promise that resolves to either a validation error object or null. Typical use cases include checking username availability, email uniqueness, or validating codes against a database. By combining async validators with synchronous validators and using options like updateOn: 'blur', you can create efficient, responsive, and reliable form validation.

Dependent fields - how to enable or disable some form fields depending on the values of other fields

Dependent fields allow one form control to influence the behaviour of another. In Angular Reactive Forms, this is typically achieved by subscribing to the valueChanges observable of one control and using methods such as enable(), disable(), setValidators(), clearValidators(), and updateValueAndValidity() to modify related controls. This approach helps create dynamic, user-friendly forms that respond intelligently to user input.

Pre-saving a form draft

Pre-saving a form draft allows users to continue working on a form without losing their progress. In Angular Reactive Forms, this is commonly implemented by subscribing to the form's valueChanges observable and saving the current values to Local Storage or a backend server. When the form is reopened, the saved data can be restored using patchValue(). For better performance, use RxJS operators such as debounceTime() to reduce unnecessary save operations, and clear the saved draft once the form is successfully submitted.

Building a multi-step form with Angular Material

Angular Material's Stepper component provides a structured way to build multi-step forms. Each step is associated with its own FormGroup (or a nested group within a parent form), allowing independent validation before users proceed. Features such as matStepperNext, matStepperPrevious, and linear navigation help create intuitive, user-friendly forms, making the stepper an excellent choice for registration, checkout, application, and other complex workflows.

Reusable nested forms (an address form)

reusable nested form is a child FormGroup extracted into its own Angular component and reused across multiple parent forms. An address form is a common example, where fields such as street, city, state, and postal code are grouped into a nested FormGroup and passed to a reusable AddressComponent. This approach reduces duplication, improves maintainability, and makes Angular Reactive Forms easier to scale and manage in large applications.

Custom File Upload Form Control

A Custom File Upload Form Control is an Angular component that implements the ControlValueAccessor interface, allowing it to behave like a standard form control. It can be used with formControlName, supports validation, and integrates with Reactive Forms. After a file is selected, it can be uploaded to a backend using FormData, making this approach ideal for handling documents, images, and other file uploads in Angular applications.

Form Arrays

A FormArray is an Angular Reactive Forms class used to manage dynamic collections of controls. Unlike a FormGroup, which uses named controls, a FormArray stores controls by index, making it ideal for forms where users can add or remove fields at runtime. It supports FormControl, FormGroup, and nested FormArray instances, providing a flexible solution for building dynamic and scalable forms.
